## Why

工作台会话列表缺少成熟 IM 常见的收件箱管理能力：置顶与折叠、列表级已读/未读、旗标、免打扰、自定义标签、消息侧分组筛选，以及打开会话后的未读定位与窗口化加载。当前红点与对端回执绑死、列表无法按未读/旗标/@我/类型等快速过滤，置顶与大未读量体验也不足。

> **状态**：本 change 为规划草案（含分组九类）。**在用户明确要求按 `tasks.md` 实现前，不得编写业务代码。** 实现顺序以 `tasks.md` / design D6 为准：先基础行版式与成员态，再分组栏，再窗口加载与 `-api`。

## What Changes

- 会话列表右键：**置顶**（区分样式 + 可折叠置顶区 + 折叠态聚合未读）、**标记已读/未读**（仅 inbox，固定未读露出 1 条）、**旗标**、**免打扰**、**标签**（二级菜单：历史库可滚动 + 新建）。
- 真实已读：**进入推进 + 停留续报**；打开未读自动定位 +「以下为新消息」+ seq 窗口加载与回最新。
- 列表行版式：身份类型标签在用户名后；头像相对双行居中；旗标在标题行右侧；免打扰静音铃 + 弱未读小红点；汇总角标不计免打扰未读。
- **消息侧分组栏**：本版分组见下表；齿轮打开「编辑分组」控制展示/隐藏与排序，**默认全部展示**。
- 自定义标签：右键打标；分组栏「标签」下展开标签列表并可按标签筛选；**会话列表行仍不强制展示标签文案**（与参考产品一致：筛选用侧栏）。
- 置顶折叠态、分组可见性/顺序经 **用户偏好多端同步**。

### 本版消息分组（筛选规则）

| 分组 | 规则 |
|------|------|
| 消息 | 全部会话（不区分已读/未读） |
| 未读 | 仅 inbox 未读 > 0 |
| 标记 | 已旗标（不区分已读/未读） |
| @我 | 仅仍有未读且含 @我 的会话（读完即离开本分组） |
| 标签 | 父级可展开；**只能点选具体标签**；该标签下会话不区分已读/未读 |
| 单聊 | `direct` 单聊（不区分已读/未读） |
| 群聊 | `group` 群聊（不区分已读/未读） |
| 免打扰 | 已免打扰（不区分已读/未读） |
| 机器人 | `bot_dm` 等机器人会话（不区分已读/未读） |

本版 **不做** 参考稿中的云文档 / 话题 / 已完成等业务分组。

## Capabilities

### New Capabilities

- `im-conversation-pin`：置顶、置顶区折叠与聚合未读；折叠偏好同步。
- `im-conversation-inbox`：列表已读/未读与回执分离；进入已读；未读分界与窗口加载。
- `im-conversation-flag`：旗标开关与列表/标题展示；分组「标记」筛选。
- `im-conversation-list-row`：列表行版式（身份标签位置、头像居中）。
- `im-conversation-tag`：标签库、右键打标/新建；分组栏按标签筛选。
- `im-conversation-mute`：免打扰、弱红点、静音铃、汇总不计 mute 未读。
- `im-conversation-groups`：消息侧分组栏、九类筛选、编辑分组（展示/隐藏/排序）。

### Modified Capabilities

- `im`：双水位、窗口 list、列表字段（pin/flag/mute/inbox/mention 等）。
- `user-preference`：`settings.im` 增加置顶折叠与分组栏可见性/顺序。

## Impact

- **模块**：`relayflow-module-im`；`relayflow-module-system`（偏好）；Flyway；`web/` `/app/messages`。
- **API**：conversation 状态与 tag；message window list；preference。
- **前端**：消息页增加分组侧栏 + 编辑分组弹层；列表与右键能力。
- **非目标（本批）**：移除会话、会话归档、定时免打扰 UI、云文档/话题/已完成分组、自定义标签在会话行上的展示、气泡已读勾大改。
